# Life Inbox

Life Inbox V1 foundation rebuilt from the supplied project and Blue Book.

## Current foundation
- Premium onboarding and brand assets
- Account entry screens
- Home / Open Loops
- Waiting On
- Add / Capture (text, image, document, speech)
- AI Detection review screen with local parser placeholder
- Open Loop detail + timeline
- Yes / Not yet / Remind later resolution flow
- Search
- Profile / privacy controls foundation
- Local persistence with SharedPreferences
- Supplied app icon installed for Android launcher sizes

## Next production integrations
- Supabase Auth/PostgreSQL/Storage + RLS
- Secure OpenAI server-side extraction
- FCM/local notification engine
- Production privacy/export/account deletion
- Android/iOS share sheet
- Store release configuration

Run `flutter pub get`, then `flutter run`.
